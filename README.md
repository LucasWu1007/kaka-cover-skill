# 咔咔封面 Skill

一套用于商业教育类封面的 Codex Skill。它把封面制作固定为同一条工作流：

1. 选择画布比例或自定义尺寸。
2. 第一轮生成四张无字小样。
3. 用户选中一张。
4. 输出选中稿的高清无字版。
5. 使用同一底图制作 AI 设计标题版。

仓库内包含老吴 Q 版人物、3D 怪兽材质、纸张水彩背景和漫画重拳标题字效参考图。

封面背景会根据主题自动选择：Meta 话题使用 Meta 后台，Google 话题使用 Google 后台或搜索页，电商话题使用商品页，线下业务使用实体店；对比主题会把不同背景放在各自阵营后方。

## 安装

```bash
git clone https://github.com/LucasWu1007/kaka-cover-skill.git ~/.codex/skills/kaka-cover
```

重新打开 Codex 后，可直接这样使用：

```text
使用 $kaka-cover，做一张 16:9 的新封面。主题是……
```

未指定尺寸时默认使用 16:9；也支持 1:1、4:5、9:16 和自定义宽高。
