# 业务背景选择

在生成四张无字稿前，先根据主题选择能解释业务语境的背景。背景应提供信息，不应只是烟雾、观众席或抽象色块。

## 场景映射

| 主题 | 优先背景 |
|---|---|
| Meta / Facebook 广告 | Meta Ads Manager 后台、广告组界面、信息流或素材预览 |
| Google Ads | Google Ads 后台、搜索广告结果页、关键词或购物广告界面 |
| Shopify / 独立站 / 电商 | 商品详情页、商品列表页、购物车、结账页或电商数据面板 |
| 线下门店 / 本地品牌 | 实体店门头、橱窗、货架、收银台或店内陈列 |
| B2B 询盘 | CRM、询盘列表、聊天窗口、表单后台或采购订单 |
| 两个平台或渠道对比 | 左右分区，每一侧使用与该阵营对应的后台或真实业务场景 |

主题没有明确平台时，选择与核心动作最相关的业务页面或真实场所，不强行加入 Meta 或 Google 后台。

## 构图规则

- 把业务背景放在对应角色或阵营后方，空间关系必须一眼可懂。
- 背景应足够大，缩略后仍能识别是后台、产品页或实体店；同时降低对比度、轻微虚化，不能抢过主体。
- 页面只需保留典型结构，例如侧栏、折线图、产品主图、价格区和购买按钮。除用户明确要求外，不生成可读的小段落、虚假数据或多余文案。
- 对比主题优先采用左右分区。例如“线下门店 vs Shopify”：门店角色后方是实体店，Shopify 角色后方是商品详情页。
- 标题区域保持干净。不要让浏览器窗口、门头或后台面板侵入标题安全区。
- 四张小样可以改变后台角度、大小和景深，但每张都必须使用语义正确的背景。
